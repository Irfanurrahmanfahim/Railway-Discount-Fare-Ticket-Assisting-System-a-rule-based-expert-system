# Railway-Discount-Fare-Ticket-Assisting-System-a-rule-based-expert-system

This project is a simple **rule-based expert system** developed using **CLIPS** (C Language Integrated Production System). It was created as an educational tool to understand the fundamentals of **Artificial Intelligence**, particularly how expert systems work.

## 💡 Purpose

The system is designed to help users find the **appropriate discount** for their journey based on a set of predefined rules. It simulates the behavior of an expert decision-making process using facts and inference rules.

## 🧠 How It Works

* The system takes **user inputs** such as age, profession, travel frequency, and other relevant factors.
* Based on a set of **if-then rules**, the system infers whether the user qualifies for a specific **discount**.
* CLIPS handles the rule matching and execution through its **forward chaining** inference engine.

## 📦 Features

* Easy to modify and extend with new rules.
* Simple user interaction through text input.
* Clear logic to demonstrate expert system principles.

## 📁 Files

* `discount-fares.clp` – Main CLIPS file containing facts, rules, and user interaction logic.
* `README.md` – This documentation.

## 🚀 Getting Started

1. Download and install [CLIPS](http://www.clipsrules.net/).
2. Load the `.clp` file in the CLIPS environment.
3. Run the program and follow the prompts.

## 📚 Learning Objective

This project aims to provide a **hands-on introduction to AI** by demonstrating:

* Knowledge representation
* Rule-based reasoning
* Expert system development
